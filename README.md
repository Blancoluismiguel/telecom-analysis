## 🧠 Objetivo del análisis

- Evaluar el comportamiento de los clientes de una empresa de telecomunicaciones en Latinoamérica, ConnectaTel.
- Construir un pipeline de limpieza reproducible para futuros analysis de otros años.
- Analizar comportamientos, distribuciones y outliers para mejor análisis de los datos.
- Generar insights para el equipo de ventas y que ellos sepan a que grupos se les puede vender mas y a que grupos pueden tener una actualización de su plan de uso.
